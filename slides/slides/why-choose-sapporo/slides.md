# 自分が住みやすい環境を求めた意思決定

- 北海道に住み続けなければいけない家庭の事情や経済的理由はない
- <span color='#20b2aa'>**北海道に住んでいること自体が自分のアイデンティティである**</span>
  - リモートにおいての話題の1つになる
  - コミュニティ活動をするとなぜか道民は集まる
    - 単純な地元愛・コミュニティ愛
    - 特に旭川市の<a href='https://asahikawa.connpass.com/' target='_blank'>ゆるい勉強会</a>に育てられて進学を決め、エンジニアになった
      - 関わった活動でそういう人が増えるといいな、ぐらいのゆるい気持ち
- ついでに道外の生活に耐えられる気がしない。気温、湿度、住居構造

# 田舎はつらい

## 移住の経緯

- 地元に戻って2年半住み、<span color='red'>住みづらさが顕著になってきた</span>
  - 外出してもやることがない → **2週間に一度程度しか外に出ない**
    - 外出先の旭川はほぼ地元。しかし友人はいない
  - 道外に出る用事があっても飛行機のみで**便数が少なく、融通が効きづらい**
- コミュニティ活動への不満はないが、<span color='#20b2aa'>他の環境も見てみたい</span>

## 移住で期待したこと

- 日常の外出も遠出も、機会を増やす
  - 札幌から旭川には日帰りで行ける(片道1時間半ぐらい)
- コミュニティ活動を増やす
- 共通の趣味のある友人がいる地域に住む

# 参加した札幌のエンジニアコミュニティ

## 定期的に勉強会が開催される札幌市内のコミュニティ
- Sapporo Engineer Base(SEB): Webや技術自体に限らず、エンジニアに関わる話題全般
- Java Do: Javaを中心に、参加した会は設計のワークショップ
- ゆるWeb勉強会@札幌: Web関連の話題全般

## 大規模イベント
- オープンソースカンファレンス北海道: 低レイヤの話題多め。コミュニティ活動の出発点
- フロントエンドカンファレンス北海道: Webフロントエンドの技術全般。100人規模の現地参加
